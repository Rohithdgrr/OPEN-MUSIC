# 01 — Mobile Tech Stack

## Core

| Layer | Technology | Version / source | Why |
| --- | --- | --- | --- |
| Shell | Tauri 2 (`tauri`, `tauri-build`) | `^2` in `app/src-tauri/Cargo.toml:14`, `app/package.json:14` | One Rust core for desktop + Android + iOS |
| Language (backend) | Rust | `edition 2021`, `rust-version 1.77` (`Cargo.toml:5-6`) | Catalog, proxy relay, vault, lyrics |
| Language (frontend) | Vanilla JS, ES modules, no bundler | `app/src/mobile/*.js` | Same "no build step" rule as desktop; WebView loads files directly |
| Styling | Tailwind CSS, prebuilt static file | `tailwindcss ^3.4.19`, `npm run css` → `app/src/tailwind.css` | No runtime CDN for utilities; `beforeDevCommand` / `beforeBuildCommand` regenerate it |
| Fonts / icons | Google Fonts + Material Symbols (CDN) | `<link>` in `app/src/mobile/index.html:8-11` | Needs network; falls back to system font / ligature text offline |
| HTTP client | `reqwest 0.12` | `Cargo.toml:56-59` — desktop = default TLS, **Android = `rustls-tls`** (no system OpenSSL on Android) | Catalog + media fetch |
| Async / server | `tokio 1` (full), `axum 0.8`, `tokio-util`, `futures` | `Cargo.toml:21-25` | Localhost range relay (`proxy.rs`) |
| Crypto / media URL | `des 0.8` + `base64 0.22` | `Cargo.toml:27-28` | `encrypted_media_url` is base64 over DES-ECB |
| Cache | `moka 0.12` (RAM) + disk tree in app cache dir | `Cargo.toml:30`, `lib.rs` cache commands | L1/L2/L4-RAM + L3/L4 disk; vault excluded |
| Vault ledger | `rusqlite 0.37` (`bundled`) | `Cargo.toml:33` | WAL SQLite, no system SQLite needed |
| Random (Drive PKCE) | `getrandom 0.2` | `Cargo.toml:18` | OAuth state |
| Tests | Rust `cargo test` + `wiremock 0.6`; JS `node --test` | `Cargo.toml:84`, `package.json:11` | Offline gate via `OP_OFFLINE=1` |

## Mobile-specific

| Item | Detail |
| --- | --- |
| Android toolchain | JDK 17 + Android SDK (API 34) + NDK r25+; Rust targets `aarch64-linux-android armv7-linux-androideabi i686-linux-android x86_64-linux-android`; managed by `tauri android` Gradle project in `app/src-tauri/gen/android/` |
| iOS toolchain | Xcode + iOS SDK on **macOS only**; Rust targets `aarch64-apple-ios aarch64-apple-ios-sim x86_64-apple-ios` (`ios.yml:65`); project generated by `npx tauri ios init --ci` |
| Media playback | Single `<audio id="audio">` in `mobile/index.html:112` + `mobile/player.js` queue/transport; lock-screen metadata via `navigator.mediaSession` (`player.js`) |
| Navigation | Hash router `mobile/router.js` (`#/home`, `#/search`, …); `window.__tmBack()` bridges Android hardware back |
| Storage | `localStorage` keys (`tm-favorites`, `tm-plays`, `tm-history`, `tm-library`, `tm-dl-quality`, …) defined in `mobile/shared.js`; vault files in app data dir (see `lib.rs` `setup`) |
| IPC | `window.__TAURI__.core.invoke` with `Channel` shim in `mobile/shared.js`; `api_version() = 1` (`lib.rs:290`) |
| CSP | Per-platform configs: desktop `tauri.conf.json:43`, Android `tauri.android.conf.json:18`, iOS `tauri.ios.conf.json:14`. Mobile ships a long `sha256-*` allow-list because screens use inline handlers. |

## Desktop-only (must stay out of mobile builds)

From `Cargo.toml:38-50` — these have **no mobile implementation** and break the
mobile build if moved to `[dependencies]`:

- `tauri-plugin-global-shortcut`, `tauri-plugin-single-instance`
- `tauri-plugin-updater` (App Store handles iOS updates)
- `tauri-plugin-dialog` (native Save/Open)
- `keyring` (OS credential store)

Windows-only: `windows-sys 0.61`, `windows 0.62` (`Cargo.toml:61-74`).

Corresponding `#[cfg(desktop)]`-only commands in `lib.rs`:
`export_file`, `read_import_file`, tray, global shortcuts, updater plugin.
Mobile stubs: `shortcuts::{register, get_shortcut_mode}` no-op (`lib.rs:27-34`),
`start_drag` no-op (`lib.rs:1020-1023`), `unminimize` no-op (`lib.rs:1056-1058`).
