CORE CAPABILITIES

Everything a serious listener needs

Search acoustic masters, keep an offline vault on disk, and play with the network off — all in one signed, self-updating package.

Search that keeps up

Songs, albums and artists with instant inline suggestions, powered by JioSaavn's first-party API plus five community mirrors as fallback.

Five quality tiers

96 kbps to 320 kbps with FLAC/DSD paths. Every track resolves to a complete file, never a preview — bit-rate and bit-depth are shown in the UI.

Offline vault

Save anything to the app's own data folder and play with zero network. Filter, search, reveal and delete from the Downloads view.

Synced lyrics

LRCLIB first, JioSaavn second — with auto-scroll, manual offset adjustment and click-to-seek on every line.

Desktop widget

An always-on-top mini window sharing the exact same player state as the main window — the two can never disagree.

Library & history

Saved collections, favourites, listening history, playlists and the platform's chart playlists — all one tap away.

INTERFACE GALLERY

Quiet surfaces, precise controls

A reductive monochrome workspace — frosted glass panels, hairline borders, and typographic hierarchy instead of chromatic noise.

OUR GOAL

One player. Every track. Zero friction.

OPEN MUSIC exists to get out of the way — search, stream, and keep lossless audio without accounts, subscriptions, or compromise.

01

Every listener, everywhere

One signed build for Windows, macOS, Linux and Android — the same experience on every device you own.

02

Quality you can hear

From 96 kbps to FLAC/DSD, every track resolves to a complete file and shows exactly what you're getting.

03

Works with the network off

Save anything to the offline vault and keep listening — no signal required, no subscription gate.

Yours to inspect

Open source, plain JavaScript, no build step. Read every line, fork it, make it yours.
